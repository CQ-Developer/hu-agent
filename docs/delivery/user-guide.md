# 使用手册（客户端）

## 1. 安装与登录

- 安装：运行企业分发的签名安装包（Windows `.exe` / macOS `.dmg`）。
- **必须登录才能使用**（ADR 0004）：启动即登录门禁。
  - 企业账号：登录页自动列出已启用身份源，点「使用 xxx 登录」→ 系统浏览器完成认证 → 自动回跳应用；
  - 本地账号：服务器地址 + 邮箱 + 密码；首次可「注册并登录」（管理员可关闭注册）。
- 登录态保存在本机系统密钥库（Windows DPAPI / macOS Keychain 保护），重启无需重复输入；
  服务端撤销会话或账号被禁用时会自动退回登录页。

## 2. 界面结构

- 左侧：会话列表（搜索全文）、工作空间切换、「打开目录」、底部「个人中心」；
- 顶部 Tab：**对话 / 市场 / 模型配置 / Skill 配置 / MCP 配置 / 工作空间 / 云同步 / 用量统计 / 权限与审计 / 关于**。

## 3. 日常使用

### 3.1 对话与工具
- 直接输入需求；模型需要读文件/执行命令时会弹**授权卡片**（允许一次 / 本会话 / 始终允许 / 拒绝），
  敏感路径（`~/.ssh`、`~/.aws` 等）与保护文件是硬拒绝；
- 每个工具调用都写入工作空间 `.hu/logs/audit.jsonl`，可在「权限与审计」查看最近决策；
- 会话历史超过上下文 70% 时自动压缩（保留最近消息 + 摘要）。

### 3.2 Skill（能力包）
- 「Skill 配置」列出全局与工作空间 Skill；启用前会展示其声明需要的工具/程序/网络；
- 目录约定：`~/.hu-agent/skills/<name>/SKILL.md`（全局）与 `<workspace>/.hu/skills/...`（工作空间，优先）；
- 市场来源的 Skill 会显示「市场」标记与服务端状态（下架/停用/撤回/删除）。

### 3.3 MCP（外部工具服务）
- 「MCP 配置」新增 server：stdio 填 command/参数/env；http/sse 填 URL/headers；
- 密钥写在表单里即写入系统密钥库，配置文件只保存 `secret://` 引用；
- 工具以 `mcp__<server>__<tool>` 注入，首次调用需授权；「测试连接」可查看工具清单与错误。

### 3.4 市场（团队资源）
- 浏览/搜索 → 详情（SKILL.md 预览、权限声明、版本列表）→ 安装 → 在 Skill 配置里启用；
- 安装会校验 sha256 并安全解压（拒绝路径逃逸/符号链接/压缩炸弹）；
- 「状态检查」会在启动、每 6 小时与手动触发时同步服务端状态：
  下架仅提示、停用/撤回/删除会**硬停用**并显示原因与替代版本，恢复后自动按原意图恢复。

### 3.5 云同步
- 「云同步」→「立即同步」：上传本地改动或拉取服务端新版本（整体快照，不做文件级合并）；
- 默认排除 `.hu/sync|logs|backups`、`node_modules`、`.git`、`dist`、`.venv`，可在
  `<workspace>/.hu/workspace.json` 的 `syncExclude` 追加；
- 冲突时不自动覆盖，提供：保留本地副本后覆盖 / 导出差异清单 / 取消；
- 历史版本可「恢复」（覆盖前自动备份到 `.hu/backups`，回滚结果会作为新版本上传）；
- 可设置定时同步（关闭/15m/30m/1h/6h/24h），冲突时自动暂停并在界面提示。

### 3.6 用量统计
- 范围：个人 / 团队 / 组织 / 全局（后三者需要相应管理员权限）；
- 展示总量、按日柱状图、按模型/成员/团队/组织明细、估算花费与激活明细，可导出 CSV。

## 4. 数据与隐私

| 数据 | 位置 | 是否上报 |
| --- | --- | --- |
| 会话与消息 | `<workspace>/.hu/sessions/*.jsonl` | 不上报（云同步开启时才上传快照） |
| 密钥 | 系统密钥库加密文件 | 永不上报 |
| 用量 | 模型/token/耗时/状态/会话哈希 | 上报（不含提示词、回复、文件路径、工具参数） |
| 审计 | `<workspace>/.hu/logs/audit.jsonl` | 不上报 |

## 5. 常见问题

| 问题 | 处理 |
| --- | --- |
| 打开应用只看到登录页 | 需要登录（企业策略）；服务端不可达时点「重试连接」 |
| 提示「服务端已停用该资源」 | 管理员停用/撤回了 Skill，按提示升级版本或联系管理员 |
| 同步冲突 | 使用云同步 Tab 的三个选项；不确定时先「导出差异清单」 |
| 想做问题上报 | 「关于」→「导出诊断包」，把 zip 发给运维（已自动脱敏） |
